# 📊 Blinkit Business Dashboard

An interactive **Blinkit Business Dashboard** developed using **Microsoft Power BI** to analyze sales performance, outlet performance, product categories, ratings, and other key business metrics.

---

## 📌 Project Overview

This project focuses on analyzing Blinkit retail data and converting raw data into meaningful business insights using Power BI.

The dashboard provides an interactive view of sales performance across different **item types, outlet types, outlet sizes, outlet locations, item fat content, and outlet establishment years**.

---

## 🎯 Project Objective

The main objective of this project is to analyze Blinkit's business performance and identify important sales and outlet-level trends using an interactive Power BI dashboard.

---

## ❓ Business Questions

- Which item types generate the highest sales?
- Which outlet types perform better?
- How does outlet size affect sales?
- How does outlet location impact sales?
- How does item visibility relate to sales?
- Which item categories have better ratings?
- How does sales vary based on item fat content?
- How does sales performance change across outlet establishment years?
- Which outlets contribute the most to overall sales?
